# AI Meal Planner

## 📌 Описание проекта

**AI Meal Planner** — Умный планировщик питания, который создаёт персональные недельные меню на основе ваших целей (похудение, набор массы, здоровое питание), бюджета и предпочтений. AI анализирует пищевую ценность, оптимизирует по калориям и стоимости, предлагает рецепты из доступных продуктов и генерирует список покупок. Помогает питаться разнообразно, полезно и экономно.

# 📈 Метрики успеха продукта

## Технические метрики

- **Среднее время отклика API:** ≤ 1 сек

- **Время генерации AI-меню:** ≤ 30 секунд

- Время отображения плана питания: ≤ 2 сек

- **Доступность системы:** ≥ 99%

- **Время формирования списка покупок:** ≤ 5 сек


## Пользовательские метрики

- **Удовлетворённость тестовых пользователей:** ≥ 75%

- **Оценка релевантности меню:** ≥ 70%

- **Количество активных тестировщиков:** ≥ 10 человек

- **Успешное прохождение e2e сценария создания плана:** ≥ 85%

- **Retention на 30-й день:** ≥ 60%

## AI-метрики

- **Корректность расчёта калорийности:** ≥ 85%

- **Точность учёта бюджетных ограничений:** ≥ 80%

- **Соответствие пищевым предпочтениям и аллергиям:** ≥ 95%

- **Доля неудачных генераций меню:** ≤ 8%

- **Баланс нутриентов в сгенерированных планах:** ≥ 90%

## 1. Краткое описание
Документ описывает ключевые сегменты пользователей, их основные проблемы, сценарии использования, ценностное предложение продукта и главную метрику успеха. Продукт — AI Meal Planner, который помогает правильно питаться, экономить время на планировании и деньги на продуктах, создавая персонализированные меню на основе целей и предпочтений.

## 2. Акторы

- **Пользователь (Primary User)** — человек, который активно использует приложение: создаёт планы питания, заполняет пищевые предпочтения, корректирует меню, использует список покупок.
- **Диетолог/Нутрициолог (Nutrition Expert)** — специалист, который может использовать систему для создания планов для своих клиентов или проверки AI-рекомендаций (расширенная роль).
- **Гость / Анонимный пользователь (Guest / Anonymous)** — может оценить примеры меню и функционал, но для создания и сохранения персонализированных планов требуется регистрация.


## 3. User Segments

Определены ключевые группы пользователей:
- **Занятые профессионалы** (30-55 лет, с напряженным рабочим графиком, которым сложно выделять время на планирование и приготовление здоровой пищи)
  
- **Люди, заботящиеся о здоровье** (25-50лет, стремящиеся к здоровому питанию и образу жизни, но испытывающие трудности в составлении сбалансированных меню)
  
- **Родители с детьми** (30-45 лет, которым нужна помощь в организации питания для всех членов семьи с учетом предпочтений и особенностей каждого)
  
## 4. Pain Points

1. **Занятые профессионалы**:
-	Нехватка времени на планирование и приготовление здоровой пищи
-	Сложность составления сбалансированных меню
-	Отсутствие идей для разнообразных и интересных блюд
2. **Люди, заботящиеся о здоровье**:
-	Трудности в соблюдении рекомендаций по сбалансированному питанию
-	Необходимость учитывать множество ограничений (аллергии, непереносимость, диеты)
-	Отсутствие мотивации и вдохновения для приготовления здоровой пищи
3. **Родители с детьми**:
-	Необходимость учитывать предпочтения и особенности питания каждого члена семьи
-	Сложность составления меню, которое понравится всем
-	Поиск рецептов, подходящих для всей семьи

  
## 5. Основные use-cases

**Цель:** помочь пользователю питаться сбалансированно, экономно и разнообразно, экономя время на планировании.

1. **Создание плана питания**
Пользователь создает персонализированный план на неделю

2. **Сохранения плана питания**
Пользователь создает персонализированный план на неделю

3. **Регистрация пользователя**  
   Пользователь успешно создает аккаунт.

4. **Изменение профиля пользователя**
   Пользователь успешно изменяет профиль.

5. **Восстановление пароля**
   Пользователь успешно восстанавливает пароль.

6. **Создание рецептов**
   Пользователь создаёт для себя рецепты.

   ## 6. Value Proposition
   
   AI Meal Planner помогает пользователям питаться сбалансированно и экономно, избавляя от рутины планирования и подсчётов, экономя время, деньги и снижая стресс от ежедневного выбора "что приготовить".

   > «Мы превращаем здоровое питание из сложной задачи в простой и автоматизированный процесс, который учитывает именно ваши цели, предпочтения и бюджет.»

## 7. North Star Metric

**Главная метрика успеха продукта:**

- Количество успешно соблюденных дней питания по созданным планам.

**Целевые значения:**

- 75% пользователей соблюдают ≥4 дней из плана в первые 4 недели использования
- Retention на 90-й день ≥ 45%
- Среднее количество планов, создаваемых активным пользователем в месяц: ≥2
- Средняя экономия на продуктах у регулярных пользователей: ≥15%

**Дополнительные ключевые метрики:**

- Процент пользователей, достигающих поставленных целей (похудение/набор/поддержание)
- Уровень удовлетворённости разнообразием меню
- Экономия времени на планировании питания и покупках

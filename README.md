# AI Meal Planner

## 📌 Описание проекта

**AI Meal Planner** — Умный планировщик питания, который создаёт персональные недельные меню на основе ваших целей (похудение, набор массы, здоровое питание), бюджета и предпочтений. AI анализирует пищевую ценность, оптимизирует по калориям и стоимости, предлагает рецепты из доступных продуктов и генерирует список покупок. Помогает питаться разнообразно, полезно и экономно.

# 🚀 MVP — AI Meal Planner

- Создание и управление профилем питания
- Авторизация и регистрация пользователей
- Обработка пользовательских параметров и генерация персонализированных меню
- История созданных планов питания и использованных рецептов
- Профиль пользователя (цели, предпочтения, бюджет, аллергии)
- Создание и управление планами питания на разные периоды
- Ввод уточняющих данных для персонализации меню (вес, рост, активность)
- Возможность экспорта списка покупок и рецептов
- Адаптация меню на основе фидбэка пользователя

# 📈 Метрики успеха продукта

## Технические метрики

- **Среднее время отклика API:** ≤ 1 сек

- **Время генерации AI-меню:** ≤ 30 секунд

- Время отображения плана питания: ≤ 2 сек

- **Доступность системы:** ≥ 99%

- **Время формирования списка покупок:** ≤ 5 сек


## Пользовательские метрики

- **Удовлетворённость тестовых пользователей:** ≥ 75%

- **Оценка релевантности меню:** ≥ 70%

- **Количество активных тестировщиков:** ≥ 10 человек

- **Успешное прохождение e2e сценария создания плана:** ≥ 85%

- **Retention на 30-й день:** ≥ 60%

## AI-метрики

- **Корректность расчёта калорийности:** ≥ 85%

- **Точность учёта бюджетных ограничений:** ≥ 80%

- **Соответствие пищевым предпочтениям и аллергиям:** ≥ 95%

- **Доля неудачных генераций меню:** ≤ 8%

- **Баланс нутриентов в сгенерированных планах:** ≥ 90%

## 1. Краткое описание
Документ описывает ключевые сегменты пользователей, их основные проблемы, сценарии использования, ценностное предложение продукта и главную метрику успеха. Продукт — AI Meal Planner, который помогает правильно питаться, экономить время на планировании и деньги на продуктах, создавая персонализированные меню на основе целей и предпочтений.

## 2. Акторы

- **Пользователь (Primary User)** — человек, который активно использует приложение: создаёт планы питания, заполняет пищевые предпочтения, корректирует меню, использует список покупок.
- **Диетолог/Нутрициолог (Nutrition Expert)** — специалист, который может использовать систему для создания планов для своих клиентов или проверки AI-рекомендаций (расширенная роль).
- **Гость / Анонимный пользователь (Guest / Anonymous)** — может оценить примеры меню и функционал, но для создания и сохранения персонализированных планов требуется регистрация.

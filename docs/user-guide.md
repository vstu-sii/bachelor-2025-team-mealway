## 🚀 Начало работы

### 📝 Экран регистрации

**Форма:**

- Email
- Password
- Repeat Password
- Кнопка: `Sing up`

**Действия:**

1. Заполните поля.

## 🔑 Экран авторизации (Вход в систему)

**Форма:**

- Email
- Password
- Ссылка: Забыли пароль?
- Кнопка: Войти
- Текст: Ещё нет аккаунта? → Ссылка: Зарегистрироваться

**Действия:**

1. Введите email/логин и пароль.
2. Нажмите Войти.
3. При успешной авторизации вы перейдёте в главное меню приложения.

## 👤 Профиль пользователя

**Отображаемая информация:**

- Аватар
- Имя пользователя
- Email
- Текущая цель (похудение/набор массы/поддержание)
- Уровень активности
- Рост, вес, возраст
- Пищевые ограничения (кратко)
- Средний бюджет на питание в неделю
- Кнопка: Редактировать профиль
  
**Действия:**

1. Просмотрите свои данные.
2. Для изменений нажмите Редактировать профиль.

## ✏️ Редактирование профиля пользователя

**Форма редактирования:**

- Аватар (загрузка нового)
- Имя пользователя
- Email (требует подтверждения)
- Рост (см)
- Вес (кг)
- Возраст
- Уровень активности (сидячий/умеренный/активный/очень активный)
- Кнопка: Сохранить изменения
- Кнопка: Отмена

**Действия:**

1. Внесите необходимые изменения в поля.
2. Нажмите Сохранить изменения.
3. Данные обновятся в вашем профиле.

## 🎯 Выбор цели питания
**Варианты целей:**

- ✅ Похудение (дефицит калорий)
- ✅ Набор мышечной массы (профицит калорий)
- ✅ Поддержание веса (баланс калорий)
- ✅ Здоровое питание (фокус на баланс нутриентов)

**Дополнительные настройки:**

- Интенсивность цели (лёгкая/умеренная/агрессивная)
- Кнопка: Далее

**Действия:**

-  Выберите основную цель.
-  При необходимости укажите интенсивность.
-  Нажмите Далее для перехода к предпочтениям.

## 🥦 Ввод пищевых предпочтений и ограничений
**Разделы формы:**

- Аллергии и непереносимости.
- Исключаемые продукты.
- Предпочитаемые продукты.

**Особенности:**

- Кнопка: Сохранить и продолжить

**Действия:**

- Отметьте аллергии и ограничения.
- Укажите исключаемые и любимые продукты.
- Выберите особенности питания.
- Нажмите Сохранить и продолжить.

##💰 Ввод бюджета на питание
**Форма:**

- Бюджет на неделю (в рублях) с ползунком или вводом
- Диапазоны: Экономный (1500-2500₽), Стандартный (2500-4000₽), Премиум (4000₽+)
- Опция: Оптимизировать стоимость максимально
- Кнопка: Сгенерировать план питания
- Кнопка: Назад (к предпочтениям)

**Действия:**

- Установите желаемый бюджет.
- При необходимости включите опцию максимальной оптимизации.
- Нажмите Сгенерировать план питания.

##📋 Окно сгенерированного плана питания
**Основные блоки:**

**Панель навигации:**

- Переключение между днями недели (Пн-Вс)
- Общая сводка: калории, БЖУ, стоимость недели
- Детализация дня:
- Завтрак, обед, ужин, перекусы
- Для каждого приёма пищи: название блюда, калории, БЖУ, время приготовления
- Кнопка Рецепт для просмотра деталей

**Боковая панель действий:**

- Кнопка: 📝 Редактировать день
- Кнопка: 🛒 Список покупок (открывает модальное окно)
- Кнопка: 💾 Сохранить план
- Кнопка: 🔄 Сгенерировать заново

**Действия:**

- Переключайтесь между днями недели.
- Нажимайте на блюда для просмотра рецептов.
- Используйте кнопки для работы со списком покупок и сохранения плана.

## 🗂️ Окно сохранённых планов питания
**Структура:**

**Фильтры и сортировка:**

- По дате сохранения (новые/старые)
- По цели (похудение/набор/поддержание)
- По статусу (активный/завершённый)
- Поиск по названию плана

**Список планов (карточки):**

- Название плана
- Период (неделя с... по...)
- Цель и калорийность
- Общая стоимость
- Дата создания
- Теги: Текущий, Любимый

**Действия с карточкой:**

- Кнопка: Открыть (переход к просмотру)
- Кнопка: Использовать (сделать активным)
- Кнопка: Удалить
- Кнопка: Дублировать

**Действия:**

- Используйте фильтры для поиска нужного плана.
- Нажмите Открыть для детального просмотра.
- Нажмите Использовать для активации плана.
- Создайте копию плана через Дублировать.

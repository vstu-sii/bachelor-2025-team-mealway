# User Guide — AI Meal Planner

## 🚀 Начало работы

### 📝 Экран регистрации

**Форма:**

- Email
- Password
- Repeat Password
- Кнопка: `Sing up`

**Действия:**

1. Заполните поля.
2. Нажмите `Sing up`.
3. Перейдите к авторизации.

## 🔑 Экран авторизации (Вход в систему)

**Форма:**

- Email
- Password
- Ссылка: Forgot password?
- Кнопка: Sing in
- Текст: Not a member yet? → Ссылка: Sing up

**Действия:**

1. Введите email и password.
2. Нажмите Sing in.
3. При успешной авторизации вы перейдёте в главное меню приложения.

## ✏️ Редактирование профиля пользователя

**Форма редактирования:**

- Username
- Name
- Surname
- Рост, вес, возраст
- Уровень активности (сидячий/умеренный/активный/очень активный)

**Действия:**

## 🎯 Выбор цели питания
**Варианты целей:**

- ✅ Weight Loss (дефицит калорий)
- ✅ Weight Gain (профицит калорий)
- ✅ Healthy diet (здоровое питание)

**Дополнительные настройки:**

- Кнопка: Next

**Действия:**

-  Выберите основную цель.
-  Нажмите Next для перехода к предпочтениям.

## 💰 Ввод бюджета на питание
**Форма:**

- Бюджет на неделю (в рублях)вводом
- Диапазоны: MIN и MAX
- Кнопка: Generate
- Кнопка: Назад (к предпочтениям)

**Действия:**

- Установите желаемый бюджет.
- Нажмите Generate, чтобы сгенерировать план питания.

##📋 Окно сгенерированного плана питания
**Основные блоки:**

**Панель навигации:**

- Переключение между днями недели (Пн-Вс)
- Общая сводка: калории.
**Детализация дня:**
- Завтрак, обед, ужин.
- Для каждого приёма пищи: название блюда, калории, БЖУ, время приготовления
- Кнопка Рецепт для просмотра деталей


**Действия:**

- Переключайтесь между днями недели.
- Нажимайте на блюда для просмотра рецептов.
- Используйте кнопки для работы со списком покупок и сохранения плана.

## 🗂️ Окно сохранённых планов питания
**Структура:**

**Список планов (карточки):**

- Название плана
- Период (неделя с... по...)
- Цель
- Дата создания


**Действия с карточкой:**

- Кнопка: Открыть (переход к просмотру)
- Кнопка: Удалить

**Действия:**

- Нажмите Открыть для детального просмотра.
- Нажмите Использовать для активации плана.

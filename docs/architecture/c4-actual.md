## Frontend

| Технология                 | Назначение                       | Обоснование                                                                                        |
| -------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------- |
| Android Studio + Kotlin| Официальная среда разработки и язык для создания нативных Android-приложений, обеспечивающие полный доступ к возможностям платформы. | Позволяет создать высокопроизводительное приложение с идеальной интеграцией в экосистему Android, поддержкой офлайн-работы и доступом ко всем системным функциям (уведомления, виджеты, сервисы здоровья), что критически важно для ежедневного планировщика питания. |

## Backend

| Технология             | Назначение                                 | Обоснование                                                                  |
| ---------------------- | ------------------------------------------ | ---------------------------------------------------------------------------- |
| FastAPI | Высокопроизводительный Python-фреймворк для создания быстрых и надёжных бэкенд-API, способных обрабатывать асинхронные запросы и сложную бизнес-логику. | Идеально подходит для интеграции с AI-сервисами благодаря асинхронности, обеспечивает быструю генерацию меню, автоматическую документацию API и легко масштабируется под растущую нагрузку, что необходимо для персонализированных вычислений в реальном времени. |

### Database

| Технология     | Назначение                       | Обоснование                                                                                                     |
| -------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------|
|  SQLite | Встраиваемая, легковесная реляционная база данных, не требующая отдельного серверного процесса, идеальная для локального хранения структурированных данных.| Позволяет реализовать полноценную офлайн-работу мобильного приложения, обеспечивая быстрый доступ к сохранённым планам питания и спискам покупок без зависимости от сетевого соединения, при минимальном потреблении ресурсов устройства. |

### AI Layer

| Сервис               | Назначение                                         | Обоснование                                                                           |
| -------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------- |
| LLM API | Внешний сервис, предоставляющий доступ к мощным языковым моделям для генерации, анализа и структурирования текстовых данных на естественном языке. | Позволяет реализовать интеллектуальное ядро приложения — генерацию персонализированных рецептов и меню на основе сложных пользовательских параметров, без необходимости обучать и развертывать собственную ресурсоемкую модель, экономя время и вычислительные ресурсы. |
